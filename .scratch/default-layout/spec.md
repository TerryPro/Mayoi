# 默认布局与统一布局控件

Status: Draft

## 背景

目标是把 Mayoi 的窗口布局对齐 VSCode 的默认体验：

- 启动时默认显示菜单栏。
- 标题栏右上角集中四个布局图标，侧边栏、面板（终端/问题）的显示与位置控制都收进这里。

现在标题栏里的按钮是分散的：侧边栏按钮跟随侧边栏停靠在哪一侧，终端按钮跟随面板停靠在哪一侧，中间的命令中心占位。用户需要在三个位置找同类开关。

## 现状（代码事实）

| 事实 | 位置 |
| --- | --- |
| Mayoi 只有一个侧边栏，`sidebarRight` 只是把它停靠到右边 | `internal/settings/settings.go` 的 `SidebarRight` |
| 侧边栏视图：资源管理器、搜索、源代码管理、大纲 | `cmd/mayoi/sidebar.go` 的 `sidebarSwitch` 调用 |
| 面板承载终端与问题，位置支持底部/左侧/右侧 | `cmd/mayoi/view.go` 的 `panelSide`、`setPanelPosition` |
| 终端可以放到编辑器区（`TerminalLocation`） | `cmd/mayoi/panel.go` |
| 侧边栏显隐在窗口状态里（`SidebarClosed`），面板显隐在窗口状态里（`PanelOpen`） | mygo 窗口状态 |
| 菜单栏是窗口内菜单条，只在非 macOS 显示，由 `settings.MenuBarExpanded` 控制，缺省为 false | `cmd/mayoi/menubar.go` |
| 视图命令齐全：`view.sidebar`、`view.panelPosition.*`、`view.terminal`、`view.problems` 等 | `cmd/mayoi/commands.go` |

## 目标布局

标题栏最右侧依次排四个图标，紧靠窗口控制按钮：

| 顺序 | 图标 | 作用 |
| --- | --- | --- |
| 1 | 自定义布局（新增四宫格图标） | 点击弹出布局菜单 |
| 2 | 侧边栏 | 显示/隐藏侧边栏（`view.sidebar`） |
| 3 | 面板 | 显示/隐藏面板（`view.terminal`） |
| 4 | 停靠右 | 侧边栏在左/右之间切换（`view.sidebarRight`） |

标题栏左侧保持不变：菜单栏显示时是各个菜单，隐藏时是汉堡按钮；中间是命令中心。

三个平台都显示这四个图标；菜单栏的默认显示只在 Windows/Linux 生效，macOS 用系统菜单栏。

## 交互

### 开关图标

- 侧边栏、面板图标复用现有图标与 `iconButton`，不做高亮，状态靠 tooltip 与菜单勾选表达。
- 面板图标的行为与 `Ctrl+`` ` 一致：面板打开时显示上次看的内容（终端或问题），首次打开默认终端。
- 停靠右图标点击后侧边栏在左右之间移动，图标随停靠方向切换。

### 自定义布局菜单

点击第一个图标弹出 `ui.Menu`，结构如下：

1. 面板位置：底部 / 左侧 / 右侧（单选，对应当前 `view.panelPosition.*`）
2. 终端与面板：终端独立于问题面板显示、终端放到编辑器区、终端锁定右侧（勾选项）
3. 侧边栏：资源管理器、搜索、源代码管理、大纲（点击切换到该视图；侧边栏隐藏时同时展开）
4. 分隔线后：恢复默认布局

### 恢复默认布局

恢复到 VSCode 式的默认状态：

- 菜单栏显示
- 侧边栏显示并停靠在左
- 面板在底部且关闭
- 终端回到面板内（清掉 `TerminalLocation` 的编辑器状态）
- 清除终端锁定右侧的状态

### 保留的入口

View 菜单、命令面板、已有快捷键（`Ctrl+B`、`Ctrl+`` ` 等）全部保留。布局控件只是多一个入口。

## 设置与迁移

- `menuBarExpanded` 改为指针布尔：未设置按显示处理；用户手动关闭时写入 `false`；旧配置里显式 `false` 的保持关闭。
- 设置键名与 `settings.json` 的 schema 条目保持不变，文档里补一句默认显示。
- 不新增布局相关的设置项。

## 非目标

- 不做真正的次级侧边栏（与左侧栏并存的第二个面板）。
- 不改终端面板自身的控制（新建终端、关闭、移到编辑器、右侧终端列表），它们留在面板头部。
- 不做 VSCode 式的悬浮缩略布局浮层。
- 不给三个开关图标加高亮状态。

## 验收点

1. 新装启动（无设置文件）时，Windows/Linux 显示菜单栏，macOS 不显示窗口内菜单栏。
2. 标题栏最右侧依次是四个图标，顺序与上文一致，窗口变窄时按钮不被挤出窗口。
3. 点击侧边栏/面板图标分别切换侧边栏与面板；面板关闭再打开时回到上次的内容。
4. 点击停靠右图标，侧边栏在左右之间移动，图标随之变化。
5. 自定义布局菜单能改组面板位置、能把终端放到编辑器区并移回、能锁定/解锁终端右侧、能切换到四个侧边栏视图，勾选状态与实际一致。
6. 恢复默认布局后，上述状态与「恢复默认布局」一节一致。
7. View 菜单、命令面板、快捷键行为不变。
8. `menuBarExpanded` 未设置时启动显示菜单栏；手动关闭后重启保持关闭。
