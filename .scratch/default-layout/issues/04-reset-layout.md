# 04: 恢复默认布局

**What to build:** 从自定义布局菜单或命令面板执行「恢复默认布局」，窗口回到默认状态：菜单栏显示、侧边栏显示并停靠在左、面板在底部且关闭、终端回到面板内、终端锁定右侧被清除。

**Blocked by:** 03

**Status:** resolved

- [x] 从任意布局状态执行后，上面五项都回到默认值
- [x] 面板位置、侧边栏位置、终端位置的改动都写入配置文件，重启保持
- [x] 自定义布局菜单底部有入口，命令面板也能搜到
- [x] 测试覆盖从「面板在左、侧边栏在右、终端在编辑器区、锁定右侧」这种反向状态恢复

## Answer

新增 `view.resetLayout` 命令（命令面板可搜）与布局菜单底部入口。`resetLayout` 重置菜单栏显示、侧边栏在左且打开、面板底部关闭、终端回面板、`panelMax=false`，并只清除最右侧锁定列（终端锁定），不动编辑器列锁定。新增 `TestResetLayout` 覆盖反向状态恢复。
